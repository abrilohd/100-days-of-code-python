# Day 36 – Stock, News & Weather Alert System 📈🌧️

A combined automation system that monitors:
- Weather forecasts (rain alerts)
- Stock price movements
- Related financial news

Alerts are delivered instantly via SMS using Twilio.

## What I Learned
- Combining multiple external APIs into one system
- Secure secret management with `.env`
- Retry logic and timeout handling
- Financial data analysis with thresholds
- Real-world notification workflows

## Technologies Used
- Python
- OpenWeatherMap API
- AlphaVantage API
- NewsAPI
- Twilio SMS
- dotenv

## Why This Matters
This project mirrors real backend services that:
- Monitor conditions
- Analyze data
- Notify users automatically

Built following professional development practices.
