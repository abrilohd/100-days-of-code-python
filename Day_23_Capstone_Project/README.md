# Day 23 – Capstone Project: Turtle Crossing Game

## Project Goal
Build a complete game using Object-Oriented Programming
where the player safely crosses a road while avoiding moving cars.

## What I Learned
- How to structure a full project using multiple classes
- Game loop control with increasing difficulty
- Collision detection and level progression
- Separating responsibilities between player, cars, and scoreboard

## Files Overview
- `player.py` → Controls player movement and finish detection
- `car_manager.py` → Creates cars, moves them, and increases speed
- `scoreboard.py` → Displays current level and game over message
- `main.py` → Controls the game flow and interactions

## Game Features
- Player movement using keyboard input
- Random car generation
- Speed increases with each level
- Level-based scoring system
- Game over on collision

## Key Takeaway
A well-structured class-based design makes
complex games easier to build, debug, and expand.
