# Day 27 – Tkinter GUI & *args / **kwargs

## Project
Universal Multi-Unit Converter built with Tkinter.

## Goal
Learn how to build real GUI applications using:
- Tkinter widgets
- *args and **kwargs concepts
- Dictionaries with lambda functions
- Clean OOP structure

## What I Practiced
- Button actions and event handling
- Entry, Label, Combobox, Listbox
- Keyboard shortcuts (Enter, Ctrl+C)
- Error handling with messagebox
- GUI layout using grid()
- History tracking inside GUI

## Files
- `click_button.py` → Basic button click practice
- `Mile_to_KiloMetre_converter.py` → Simple conversion GUI
- `Multi_Unit_Converter.py` → Multiple conversions logic
- `playground.py` → Tkinter testing area
- `Project_Multy_Unit_converter.py` → Final polished GUI project

## Outcome
A user-friendly universal converter
that supports multiple unit conversions
with clean, readable, scalable code.
