Accessible Government Portal

November 2025 - Present

Project Description

Redesigned a government website to meet WCAG 2.1 AA standards using clear headings, semantic structure, and ARIA landmarks. The site works without CSS or JavaScript.

Technical Implementation

  • Used semantic elements like <main>, <nav>, and <article>
  • Added skip links and clear focus order for keyboard users
  • Built accessible forms with correctly associated labels
  • Structured data tables with proper scope attributes

Tools & Technologies

  1. HTML5 Semantic Elements
  2. WAI-ARIA
  3. NVDA Screen Reader Testing
  4. Lighthouse Auditing

Achievement: High accessibility results from testing
