# HTML & CSS Portfolio

A simple, multi-page portfolio website built with **semantic HTML** and **clean CSS**.  
No frameworks. No JavaScript. Just solid web fundamentals.

## Project Structure

portfolio/
├── index.html
├── about.html
├── projects.html
├── contact.html
├── css/
│ └── style.css

## What This Project Shows

- Semantic HTML5 structure
- Accessibility-friendly markup
- External CSS styling
- Clean layout and typography
- Multi-page website organization
- Real-world contact form

## Tech Used

- HTML5  
- CSS3

Open `index.html` in your browser and navigate using the menu.
