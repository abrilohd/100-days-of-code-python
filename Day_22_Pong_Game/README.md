# Day 22 – Pong Game (OOP with Turtle)

## What I Learned
- How to design a full game using Object-Oriented Programming
- How to separate logic into multiple classes (Paddle, Ball, Scoreboard)
- How to manage game states (start screen, playing, game over)
- How to handle collisions, scoring, and speed control

## Files Overview
- `paddle.py` → Controls paddle movement and boundaries
- `ball.py` → Handles ball movement, bouncing, and speed
- `scoreboard.py` → Manages score display and game over screen
- `main.py` → Game controller (screen setup, loop, inputs)

## Game Features
- Start screen with instructions
- Two-player controls (keyboard)
- Ball speed increases on paddle hit
- Score tracking and win condition
- Clean game over screen

## Key Takeaway
Breaking a game into small, focused classes
makes complex behavior easy to manage and extend.
