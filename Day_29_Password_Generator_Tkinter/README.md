# Day 29 – Password Generator & Manager (Tkinter)

## Project
A desktop Password Generator and Password Manager built using Python and Tkinter.

## Goal
Learn how to:
- Build real-world GUI applications
- Generate secure random passwords
- Work with files for data persistence
- Use pop-up dialogs for validation
- Integrate clipboard functionality

## Features
- Random strong password generator
- Mix of letters, numbers, and symbols
- One-click copy to clipboard
- Save website, email, and password to file
- Input validation with pop-up alerts
- Clean and simple Tkinter UI

## Key Concepts Practiced
- Tkinter layouts (Grid)
- GUI event handling
- File handling (`data.txt`)
- Randomization and security basics
- Clipboard automation (`pyperclip`)
- User-friendly validation dialogs

## Files
- `main.py` → Full application logic
- `logo.png` → UI logo image
- `data.txt` → Stored passwords (auto-created)

## Outcome
A functional password manager application
that demonstrates real-world GUI development
and prepares the foundation for advanced projects.
