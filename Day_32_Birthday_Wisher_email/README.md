# Day 32 – Birthday Wisher Email 🎉

## What I Built
An automated birthday email sender that checks a CSV file daily and sends personalized emails using SMTP.

## Concepts Practiced
- `datetime` for date handling
- CSV data processing with pandas
- Email automation using `smtplib`
- Randomized templates

## How It Works
- Reads birthdays from a CSV file
- Matches today’s date
- Selects a random letter template
- Sends a personalized email automatically

## Why This Matters
This project demonstrates real-world automation, useful for reminders, notifications, and backend services.
