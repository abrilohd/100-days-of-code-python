# Day 7 – Hangman Game 🎯🪢

## What I Built Today

Today I built a **command-line Hangman game** using Python.
This project helped me combine **everything I learned so far** into a real mini-game.

---

## Concepts I Practiced 🧠

* `while` loops
* `if / else` conditional statements
* Lists and strings
* Importing modules and files
* Tracking game state (lives, win/lose)
* User input validation
* Game logic and flow control

---

## How the Game Works 🎮

1. The program randomly selects a word.
2. The player guesses one letter at a time.
3. Correct guesses reveal letters in the word.
4. Wrong guesses reduce lives.
5. The game ends when:

   * All letters are guessed → **You Win**
   * Lives reach zero → **You Lose**
