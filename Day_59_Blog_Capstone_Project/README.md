# Day 59 - Blog Capstone Project

## 📌 Overview
A dynamic blog web application built with Flask.  
Blog posts are fetched from an external API and rendered using Jinja templating.

This project demonstrates:
- Flask routing
- Dynamic URLs
- Jinja templating
- Template inheritance
- External API integration
- Error handling

---

## 🛠 Tech Stack
- Python
- Flask
- Jinja2
- HTML5
- CSS3
- Bootstrap
- REST API (npoint.io)
