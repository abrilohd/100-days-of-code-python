# Day 19 – More on Turtle & Keyboard Control 🐢⌨️

## What I Learned
- How to listen for keyboard events using `screen.listen()`
- How to bind keys to functions with `onkey()`
- How to control turtle movement manually (forward, backward, turn)
- How heading and angles work in Turtle
- How to reset and clear drawings programmatically

## Files
- `Listen_on_keyboard.py` → Control a turtle using keyboard keys (W, A, S, D)
- `Turtle_Race.py` → Practice with multiple turtles and movement logic
- Other practice files → Exploring interaction and events

## Key Controls Used
- **W** → Move forward  
- **S** → Move backward  
- **A** → Turn left  
- **D** → Turn right  
- **C** → Clear screen and reset turtle  

## Key Takeaway
Keyboard events make programs interactive.
This is the foundation for real games, simulations, and user-controlled graphics.
