# Day 39 – Flight Deals Finder ✈️

An automated flight price monitoring system that tracks destinations,
checks real-time flight prices, and sends SMS alerts when cheaper deals
are available.

## What I Learned
- Structuring large Python projects with OOP
- Integrating multiple APIs in one system
- Automating price comparison logic
- Using Google Sheets as a lightweight database
- Sending real-time SMS notifications
- Environment variable management for security

## Technologies Used
- Python
- Tequila (Kiwi) Flight Search API
- Sheety API (Google Sheets)
- Twilio SMS API
- requests
- python-dotenv

## Why This Matters
This project mirrors real-world travel deal platforms and demonstrates
how automation can save time, money, and manual effort.
