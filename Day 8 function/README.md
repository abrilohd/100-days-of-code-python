# Day 8 – Functions & Caesar Cipher 🔐

## What I Learned Today
- How to create and call functions in Python
- Difference between parameters and arguments
- Using keyword arguments in functions
- How to reuse logic instead of repeating code
- How functions make programs clean and readable

## Concepts Practiced
- `def` keyword
- Function inputs and return values
- Conditional logic inside functions
- Loops with functions
- Modulus operator (%) to handle large numbers
- Handling non-letter characters safely

## What I Built
- Simple greeting functions to understand how functions work
- An encode/decode program using functions
- A full **Caesar Cipher** project that:
  - Encrypts and decrypts messages
  - Handles spaces, numbers, and symbols
  - Allows the user to restart the program
  - Keeps working even with large shift values

## Key Takeaway
Functions help break big problems into small, reusable pieces and make programs easier to understand and maintain.
