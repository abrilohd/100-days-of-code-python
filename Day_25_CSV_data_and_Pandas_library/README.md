# Day 25 – CSV Data & Pandas Library

## Project
U.S. States Guessing Game using Turtle graphics and Pandas.

## Goal
Learn how to read, write, and manage CSV data using Pandas
while building a practical, interactive project.

## What I Practiced
- Reading CSV files with Pandas
- Writing data to CSV files
- Working with DataFrames
- File existence checks using `os`
- Tracking user progress and performance
- Separating logic for better understanding

## Features
- Guess U.S. states on a map
- Timer-based gameplay
- Save missing states to `states_to_learn.csv`
- Log wrong guesses to `wrong_guesses.csv`
- Leaderboard stored in `leaderboard.csv`
- Sort leaderboard by performance

## Files
- `main.py` → Full version with leaderboard, timer, and CSV tracking
- `state_game.py` → Make U.S. States Game Simplified version for concept clarity
- `main_2.py` → Make Ethiopia Regions Challenge Practice version to reinforce CSV & Pandas usage
- `50_states.csv` → Game data source

## Key Lesson
Data handling + clean project structure
turn small scripts into real applications.
