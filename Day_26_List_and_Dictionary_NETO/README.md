# Day 26 – List & Dictionary Comprehension (NATO Alphabet)

## Project
NATO Phonetic Alphabet Converter using
List Comprehension, Dictionary Comprehension, Pandas, and Tkinter.

## Goal
Understand how Python comprehensions make code:
- Shorter
- Cleaner
- More readable
- More professional

## What I Practiced
- List comprehension
- Dictionary comprehension
- Reading CSV files with Pandas
- Mapping data efficiently
- Error handling with try/except
- Simple GUI using Tkinter

## Files
- `list_comprehension.py` → Practice examples for list comprehension
- `dictionary_comprehension.py` → Practice examples for dictionary comprehension
- `main.py` → Console-based NATO phonetic converter
- `Tkinter.py` → GUI-based NATO phonetic converter
- `nato_phonetic_alphabet.csv` → Data source

## Key Concept
One line of comprehension can replace
multiple lines of loops and conditionals.

## Outcome
Convert any word into its NATO phonetic code
using clean, Pythonic logic.
