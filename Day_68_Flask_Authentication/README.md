# 🔐 Day 68 - Production Authentication System

A secure and scalable Flask authentication system using:

- Flask-Login
- SQLAlchemy
- Secure password hashing
- Protected routes
- Download restrictions

---

## 🚀 Features

- User registration
- Secure login/logout
- Password hashing (PBKDF2)
- Login-required routes
- Protected file downloads
- Flash messaging system

---

## 🛠 Tech Stack

- Python
- Flask
- Flask-Login
- SQLAlchemy
- Werkzeug Security
