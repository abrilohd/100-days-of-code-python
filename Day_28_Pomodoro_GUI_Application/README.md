# Day 28 – Pomodoro GUI Application (Tkinter)

## Project
Pomodoro Timer built using Python and Tkinter.

## Goal
Learn how to manage time-based logic and GUI updates using:
- Tkinter widgets
- `after()` scheduling
- Global state management
- Canvas and image handling

## Features
- 25-minute work sessions
- Short and long breaks
- Automatic session switching
- Visual timer with countdown
- Check marks for completed work sessions
- Reset functionality

## Key Concepts Practiced
- Event-driven programming
- Tkinter `Canvas`
- Timer recursion with `after()`
- GUI state updates
- Basic productivity app design

## Files
- `main.py` → Complete Pomodoro Timer logic
- `tomato.png` → UI image asset

## Outcome
A functional Pomodoro Timer GUI
that reinforces focus, discipline,
and real-world GUI programming skills.
