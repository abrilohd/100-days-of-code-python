REST APIs

Representational State Transfer - Architectural style for distributed systems

🌐 What is a REST API?

REST (Representational State Transfer) is an architectural style for designing networked applications. REST APIs use HTTP requests to perform CRUD operations on resources, which are represented as JSON or XML. The key principles include statelessness, client-server separation, and uniform interfaces.

HTTP Methods in REST

GET

Retrieve data from the server. Safe and idempotent operations that don't modify resources.

GET /api/users - Get all users GET /api/users/1 - Get user with ID 1
POST

Create a new resource on the server. Not idempotent - multiple requests create multiple resources.

POST /api/users - Create new user POST /api/posts - Create new post
PUT

Update or replace an existing resource. Idempotent - same request produces same result.

PUT /api/users/1 - Replace user data PUT /api/posts/5 - Update entire post
PATCH

Partially update an existing resource. Only modify specified fields.

PATCH /api/users/1 - Update email only PATCH /api/posts/5 - Update title
DELETE

Remove a resource from the server. Idempotent - repeated calls have same effect.

DELETE /api/users/1 - Remove user DELETE /api/posts/5 - Delete post

HTTP Status Codes

200

OK

Successful GET, PUT, PATCH, or DELETE operations

201

Created

Successful POST request creating a new resource

400

Bad Request

Invalid request format or parameters

403

Forbidden

Authentication succeeded but action not allowed

404

Not Found

Requested resource doesn't exist

500

Server Error

Internal server error occurred

Flask REST API Example

from flask import Flask, jsonify, request
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    
    def to_dict(self):
        return {
            'id': self.id,
            'username': self.username
        }

@app.route('/api/users', methods=['GET'])
def get_users():
    users = User.query.all()
    return jsonify([user.to_dict() for user in users]), 200

@app.route('/api/users/<int:id>', methods=['GET'])
def get_user(id):
    user = User.query.get(id)
    if user:
        return jsonify(user.to_dict()), 200
    return jsonify({'error': 'User not found'}), 404
