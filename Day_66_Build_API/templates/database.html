Understanding Databases & ORM

From relational databases to object-oriented mapping

📊 What is a Database?

A database is an organized collection of structured information, or data, typically stored electronically in a computer system. Databases are designed to efficiently store, retrieve, and manage large amounts of information. In web applications, databases persist user data, application state, and business logic information.

Key Properties: Persistence, ACID compliance, Scalability, Data integrity

🔄 What is ORM?

Object-Relational Mapping (ORM) is a programming technique that converts data between incompatible type systems in object-oriented programming languages and relational databases. SQLAlchemy, our ORM of choice, creates a "virtual object database" that can be used from within Python code.

Benefits: Write Python instead of SQL, Automatic query generation, Relationship handling, Database abstraction

Database vs Object-Oriented Concepts

Relational Database

Table A collection of related data organized in rows and columns
Row A single record in a table containing all columns defined
Column A field type that stores a specific attribute of data
Primary Key Unique identifier for each row in the table
Foreign Key Links tables together through shared columns

SQLAlchemy ORM

Class Python class that defines the structure of database table
Object Instance of a class representing one row of data
Attribute Class property mapping to database column
Identity Map Ensures each object is unique and tracked
Relationship Defines links between different model classes

SQLAlchemy Model Example

from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class User(db.Model):
    __tablename__ = 'users'
    
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)
    posts = db.relationship('Post', backref='author')
    
    def __repr__(self):
        return f'<User {self.username}>'

class Post(db.Model):
    __tablename__ = 'posts'
    
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(200), nullable=False)
    content = db.Column(db.Text, nullable=False)
    user_id = db.Column(db.Integer, db.ForeignKey('users.id'))
