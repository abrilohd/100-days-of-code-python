CRUD Operations

Create, Read, Update, Delete - The four pillars of persistent storage

➕

Create

Add new records to the database. In SQLAlchemy, this involves creating a new model instance and adding it to the session.

new_user = User(username='john', email='john@example.com')
db.session.add(new_user)
db.session.commit()
📖

Read

Query and retrieve data from the database. SQLAlchemy provides a powerful query interface.

users = User.query.all()
user = User.query.get(1)
admins = User.query.filter_by(role='admin').first()
✏️

Update

Modify existing records. Simply update object attributes and commit.

user = User.query.get(1)
user.email = 'newemail@example.com'
db.session.commit()
🗑️

Delete

Remove records from the database. Delete the object and commit.

user = User.query.get(1)
db.session.delete(user)
db.session.commit()

CRUD in REST APIs

How CRUD operations map to HTTP methods and routes in a Flask REST API

Operation HTTP Method Example Route SQLAlchemy Method
Create POST /api/users db.session.add()
Read (All) GET /api/users User.query.all()
Read (One) GET /api/users/1 User.query.get(id)
Update PUT /api/users/1 db.session.commit()
Update (Partial) PATCH /api/users/1 db.session.commit()
Delete DELETE /api/users/1 db.session.delete()

Flask Route Example

@app.route('/api/users', methods=['GET'])
def get_users():
    users = User.query.all()
    return jsonify([user.to_dict() for user in users]), 200

@app.route('/api/users', methods=['POST'])
def create_user():
    data = request.get_json()
    user = User(username=data['username'], email=data['email'])
    db.session.add(user)
    db.session.commit()
    return jsonify(user.to_dict()), 201
