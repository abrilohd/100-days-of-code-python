# Day 14 – Higher Lower Followers Game 🎮

## What I built
Today I built a **Higher–Lower style game** where the player compares two public figures and guesses who has more followers.

## What I learned
- Using dictionaries and lists together
- Importing data from other Python files
- Random selection using `random.choice()`
- Writing reusable functions
- Game loop logic and score tracking
- Clearing the console for a better user experience

## How the game works
1. Two accounts are shown (A and B)
2. The player guesses who has more followers
3. Correct guesses increase the score
4. A wrong guess ends the game

Breaking a game into small functions makes the code easier to read, test, and improve.
