# Day 65 – Web Design School (UI/UX Foundations)

## 📌 Overview

Today focuses on learning the foundations of web design and user experience.

Instead of backend development, this day strengthens:

- Visual design thinking
- UI hierarchy
- Typography selection
- Color theory
- UX psychology
- Practical design application

---

## 🎯 Topics Covered

### 🎨 Color Theory
- Understanding primary, secondary, complementary colors
- Creating harmonious palettes
- Using tools like Adobe Color & Color Hunt

### 🔤 Typography
- Serif vs Sans-serif
- Font pairing techniques
- Readability vs aesthetics
- Visual hierarchy through font size & weight

### 🧠 UX Design
- Designing for clarity
- Reducing cognitive load
- User-first thinking
- Managing user attention

### 👁 UI Design Principles
- Visual hierarchy
- Spacing & alignment
- Contrast
- Consistency
- White space usage

### 🛠 Practical Application
- Applying design principles to real layouts
- Evaluating website inspirations
- Using Canva for mockups

## 🧠 Key Takeaways

- Good design improves usability.
- Simplicity increases conversion.
- Visual hierarchy guides attention.
- Color influences emotion.
- Typography affects credibility.
- UX determines retention.

Strong design skills allow you to:

- Build better SaaS interfaces
- Improve conversion rates
- Design without relying entirely on designers
- Create premium-looking products
