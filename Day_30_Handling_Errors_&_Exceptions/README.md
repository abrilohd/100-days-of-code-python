# Day 30 – Handling Errors & Exceptions (Password Manager with JSON)

## Project
An upgraded Password Manager application that saves and retrieves data
using JSON and gracefully handles runtime errors and missing files.

## Goal
Learn how to:
- Handle errors using try / except / else / finally
- Persist structured data using JSON
- Safely read/write files
- Prevent app crashes from missing files or invalid input
- Implement search functionality

## Features
- Generate strong random passwords
- Save passwords in JSON format
- Search stored credentials by website
- Error handling for missing files
- Input validation with user-friendly alerts
- Clean Tkinter-based GUI

## Key Concepts Practiced
- Exception handling (`FileNotFoundError`, `KeyError`)
- Raising custom exceptions
- JSON read/write operations
- Dictionary updates
- Defensive programming
- GUI error messaging with Tkinter

## Files
- `Project_Save_with_JSON.py` → Main password manager app
- `exception_main.py` → Practice file for error handling concepts
- `data.json` → Stored credentials (auto-created)
- `logo.png` → App logo image

## Outcome
A professional-grade password manager
that safely stores data, recovers from errors,
and demonstrates real-world Python application design.
