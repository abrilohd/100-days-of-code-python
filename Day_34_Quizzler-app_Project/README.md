# Day 34 – Quizzler App 🧠

A quiz application built using Python, Tkinter, and Object-Oriented Programming principles.

## What I Practiced
- API-based question data
- Object-Oriented Design (Question, QuizBrain, UI)
- Separation of concerns
- Event-driven GUI programming
- Real-world project structure

## Project Structure
- `main.py` – App entry point
- `data.py` – Question data source
- `question_model.py` – Question class
- `quiz_brain.py` – Quiz logic
- `ui.py` – Tkinter user interface
- `images/` – UI assets

## Outcome
A fully interactive quiz app that tracks score, validates answers, and updates the UI dynamically.
