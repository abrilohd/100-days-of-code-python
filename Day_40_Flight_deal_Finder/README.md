# Day 40 – Flight Deal Finder (Capstone Project – Part 2) ✈️📩

An advanced flight deal monitoring system that tracks prices,
detects discounts, and sends alerts via SMS and Email.

## Key Improvements Over Part 1
- Email notifications added
- Centralized configuration system
- Environment variable security
- Scheduler support for automation
- Better error handling & retries
- Cleaner project structure

## Features
- Real-time flight price tracking
- Google Sheets as backend storage
- SMS alerts via Twilio
- Email alerts via SMTP
- Automated scheduled checks
- Scalable and modular architecture

## Technologies Used
- Python
- Flight Search API (Tequila / Amadeus)
- Sheety API
- Twilio
- SMTP (Email)
- python-dotenv

## Why This Project Matters
This capstone mirrors real-world backend automation systems used
by travel platforms and deal aggregators.
