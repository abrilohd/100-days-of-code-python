# 🧱 Day 74 – LEGO Data Analysis Project

This project analyzes LEGO datasets to discover trends in product releases, themes, and complexity over time.

---

## 📊 Key Questions Answered

- How many LEGO colors exist?
- When were the first LEGO sets released?
- Which themes have the most sets?
- How did LEGO grow over time?
- Did LEGO sets become more complex?

---

## 🛠 Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 📈 Key Insights

- LEGO started in 1949
- LEGO created 135 colors
- Number of sets increased dramatically after 2000
- Sets became larger and more complex
- Licensed themes dominate
