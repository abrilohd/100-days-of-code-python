# Day 18 – Turtle Graphics & Mini Games 🐢🎮

## What I Learned
- How to use the `turtle` module for drawing and animation
- How the screen, turtles, shapes, and movement work together
- How to control objects using keyboard input
- How to build simple visual games using loops and collision logic
- How timing (`time.sleep`) affects animation and gameplay

## Files
- `Day18StartTurtle.py` → Basic turtle movement and drawing (square)
- `main.py` → Dot painting using colors and positioning
- `Love_Hurts.py` → Animated heart and arrow drawing
- `catch_the_heart_Project.py` → Interactive shooting game using Turtle

## Mini Project – Catch the Heart 💘
- Player moves left and right
- Shoots bullets to catch falling hearts
- Score, levels, and missed hearts are tracked
- Game ends after too many misses

## Key Takeaway
Turtle helps beginners understand graphics, movement, coordinates,
and game logic in a fun and visual way.
