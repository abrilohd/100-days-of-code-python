# Day 13 – Debugging in Python 🐞

## What I learned
Today I practiced debugging by identifying and fixing common Python errors such as:
- Logical errors in loops
- Index errors
- Conditional mistakes
- Type errors
- Indentation errors
- Variable assignment bugs

## Key skills practiced
- Reading error messages
- Reproducing bugs
- Using print statements to trace issues
- Understanding why code fails, not just how to fix it

## Takeaway
