# Day 11 – Blackjack Game 🃏

## What I Learned Today
- How to break a big program into small functions
- How to control game flow using loops and conditions
- How to manage game state (win, lose, draw)
- How to simulate real-world rules using code
- How to restart a program cleanly

## Concepts Practiced
- Functions with clear responsibilities
- Lists to store cards
- Random choice for card dealing
- Conditional logic for game rules
- Loops for continuous gameplay
- Returning values from functions
- Using `0` as a special value (Blackjack)

## What I Built
- A complete **Blackjack (21) game**
- Features:
  - User vs computer gameplay
  - Unlimited card deck
  - Automatic Ace handling (11 or 1)
  - Blackjack detection
  - Computer AI logic (draw until 17)
  - Game restart option
  - Clean console output with logo

## Key Takeaway
Large programs become easy to manage when they are divided into small, well-defined functions.
