# Day 45 – Beautiful Soup Web Scraping

## What I Learned
- How web scraping works
- Parsing HTML with BeautifulSoup
- Extracting text, links, and numerical data
- Writing scraped data to files

## Projects
### 1. Hacker News Scraper
- Scrapes Hacker News articles
- Finds the most upvoted post
- Prints title, link, and score

### 2. Top 100 Movies Scraper
- Scrapes a movie ranking website
- Extracts movie titles
- Saves them in correct order to a text file

## Tools Used
- Python
- requests
- BeautifulSoup (bs4)

## Outcome
Built real-world scrapers that transform web data into usable information.
