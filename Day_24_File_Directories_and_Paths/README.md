# Day 24 – Files, Directories & Paths

## Project
Enhanced Snake Game with restart and score reset logic.

## Goal
Learn how Python projects are organized across multiple files
and prepare for working with files, directories, and paths.

## What I Practiced
- Importing classes from different files
- Organizing code into modules
- Game reset without restarting the program
- Keyboard control for restarting the game
- Clean separation of logic (Snake, Food, Scoreboard)

## New Feature
- Press **R** to restart the game
- Score and snake reset after collision

## Files
- `main.py` → Game loop and controls
- `snake.py` → Snake behavior
- `food.py` → Food generation
- `scoreboard.py` → Score handling and reset logic

## Key Lesson
Good folder and file structure makes programs
easier to read, maintain, and expand.
