# Day 38 – Workout Tracking with Google Sheets 🏋️‍♂️📊

A workout tracking application that converts natural language exercise input
into structured fitness data using the Nutritionix API and stores it in
Google Sheets via the Sheety API.

## What I Learned
- Using Natural Language APIs to process human input
- Chaining multiple APIs in a single workflow
- Secure API key management with environment variables
- Writing structured data to Google Sheets programmatically
- Bearer token authentication

## Technologies Used
- Python
- Nutritionix Natural Language API
- Sheety API (Google Sheets)
- requests
- python-dotenv

## Why This Matters
This project demonstrates how real fitness, health, and productivity
applications transform user input into actionable data stored in the cloud.
