# Day 37 – Habit Tracking API 🚴‍♂️📊

A habit tracking system built using the Pixela API that records daily activity
and visualizes progress on a graph.

## What I Learned
- Working with REST APIs (POST, PUT, DELETE)
- Secure API token handling using `.env`
- Date formatting for API data consistency
- Designing reusable API functions

## Technologies Used
- Python
- Pixela API
- requests
- python-dotenv

## Why This Matters
This project simulates real-world data tracking systems used in
health, productivity, and analytics applications.
