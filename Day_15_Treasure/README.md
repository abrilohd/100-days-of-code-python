# Day 15 – Treasure Island Game 🏝️

## What I built
Today I built a **text-based adventure game** where the player makes choices to find hidden treasure.

## What I learned
- Using nested `if / elif / else` statements
- Handling user input correctly with `.lower()`
- Controlling game flow using conditions
- Writing interactive story-based programs
- Understanding how logic paths affect outcomes

## How the game works
1. The player starts at a crossroads
2. Each decision leads to a new situation
3. Wrong choices end the game
4. Correct choices lead to winning the treasure
