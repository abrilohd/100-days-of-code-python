# Day 10 – Calculator Using Functions 🧮

## What I Learned Today
- How to use functions to perform specific tasks
- How to store functions inside a dictionary
- How to call functions dynamically
- How to reuse functions to avoid repeating code
- How to build a continuous program using loops

## Concepts Practiced
- Functions with parameters and return values
- Dictionary of operations
- Looping with `while`
- User input and output
- Calling functions from dictionaries
- Recursion to restart the program

## What I Built
- A calculator that performs:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- The calculator:
  - Shows available operations
  - Allows continuous calculations
  - Can restart after exiting
  - Uses clean and reusable functions

## Key Takeaway
Using functions and dictionaries together makes programs flexible, powerful, and easy to extend.
