# Day_2 – BMI Calculator

This exercise calculates a user's Body Mass Index (BMI) based on height (meters) and weight (kg).

## Features
- User input for height and weight  
- Automatic type conversion  
- BMI calculation  
- Rounded BMI result

## Formula
BMI = weight / (height × height)

## Files
- `Day2BMI.py` → BMI calculator script  
- `Day2Note` → Notes about data types and type conversion
