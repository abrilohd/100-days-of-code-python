## 🚀 Project Summary

This automation bot:
- Measures real internet speed using Speedtest by Ookla
- Compares actual results with promised ISP speeds
- Logs into Twitter
- Posts a formatted complaint automatically if speeds are below expectations

This project simulates real-world QA + automation + monitoring workflows.

## 🎯 Purpose

Modern automation is not just clicking buttons.  
This project demonstrates:
- Multi-site automation
- Credential management via environment variables
- Browser window handling
- Dynamic content extraction
- Real-world conditional automation logic
- Class-based Selenium architecture
