# 🚀 Day 67 – Production Ready Flask Blog

A secure, SEO-friendly blog built with Flask, SQLAlchemy, WTForms, and CKEditor.

---

## 📌 Features

- Create, edit, delete blog posts
- Slug-based SEO URLs
- Admin-protected publishing
- SQLite database
- CKEditor rich text support
- Bootstrap 5 UI
- Production-ready configuration

---

## 🛠 Tech Stack

- Python
- Flask
- Flask-SQLAlchemy
- Flask-WTF
- Flask-Bootstrap
- Flask-CKEditor
- SQLite
