# Day 01 — Hello & Inputs

What: 
A tiny Python script that prints greetings, shows string concatenation, and reads user input.

How to run:
1. Open terminal in repository root.
2. Run:
    python day-001/Day1print.py

What you’ll see:
- Three hello messages printed.
- Example of concatenating strings.
- Prompts asking for your name, father's name, and a number.

Notes:
- This is a beginner friendly example. It includes basic input validation for numbers.
- No secrets or passwords are used.
