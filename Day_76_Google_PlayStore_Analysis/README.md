# 📱 Day 76 – Google Play Store Data Analysis & Visualization

A comprehensive data analysis project exploring Android app market trends using interactive Plotly visualizations.

This project analyzes thousands of apps from the Google Play Store to uncover insights about:

- App ratings
- Downloads
- Revenue potential
- Pricing strategies
- Category competition

---

# 🎯 Objectives

Understand the Android app ecosystem by analyzing:

- Most popular app categories
- Highest grossing apps
- Free vs paid app performance
- Revenue potential by category
- User engagement patterns

---

# 🛠 Technologies Used

- Python
- Pandas
- Plotly
- Jupyter Notebook

---

# 📊 Key Features & Analysis

## Data Cleaning
- Removed NaN values
- Removed duplicates
- Converted installs and price to numeric format

## Revenue Estimation
Estimated revenue using:

Revenue = Installs × Price

## Interactive Visualizations

Created professional interactive charts using Plotly:

- Pie charts (content ratings)
- Bar charts (category popularity)
- Scatter plots (competition vs downloads)
- Box plots (revenue, installs, pricing)

---

# 📈 Key Insights

- Free apps dominate download volume
- Games generate highest revenue
- Highly competitive categories have lower individual success rates
- Paid apps earn significantly less installs but higher revenue per user
- Pricing strategy varies significantly by category
